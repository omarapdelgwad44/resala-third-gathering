# حكايات رسالة — لقاء الثلث الثالث

موقع دعوة عربي باتجاه RTL بطابع أرشيف/كولاج تحريري، مع واجهة عامة ولوحة إدارة محمية، مبني بـ React وTypeScript وVite وSupabase. أُنشئ هذا المشروع كي يُنشر على GitHub Pages.

## ما يتضمنه

- صفحة عامة تستجيب للهاتف وتعرض تفاصيل اللقاء والبرنامج وبطاقات التكريم.
- نموذج RSVP يكتب الردود عبر دالة PostgreSQL محدودة؛ ولا يستطيع الزائر قراءة ردود الآخرين.
- روابط دعوات شخصية برمز عشوائي لا يضع اسم المدعو في عنوان URL.
- لوحة إدارة لتعديل النص والموعد والمكان، إظهار/إخفاء الأقسام، إدارة البرنامج والمكرّمين، رفع الصور، إنشاء الروابط الشخصية، وتصدير الردود CSV.
- مؤشرات مجمعة تقريبية للزيارات والنقرات والردود؛ لا تُجمع عناوين IP أو بصمات المتصفح.
- صور المكرّمين غير مضافة افتراضيًا. لا ترفع صورة أو اسمًا إلى الصفحة العامة إلا بعد التأكد من موافقة صاحبه.

## التشغيل محليًا

1. ثبّت Node.js 22.12 أو أحدث.
2. انسخ `.env.example` إلى `.env.local` وأضف رابط Supabase ومفتاح **publishable** العام فقط.
3. شغّل `npm ci` ثم `npm run dev`.
4. شغّل `npm run build` لفحص TypeScript وإنشاء `dist/`.

لا تضع `service_role` أو أي مفتاح سري في ملفات الواجهة أو GitHub Pages. مفتاح `publishable` يُرسل إلى المتصفح عمدًا؛ أمان البيانات قائم على RLS وقيود قاعدة البيانات.

## قاعدة البيانات وSupabase

المخططات موجودة في `supabase/migrations/`. المشروع المرفق أنشأ هذه الجداول بسياسات RLS، وترك الدعوة **غير منشورة** حتى يملأ المنظم الموعد والمكان ويتأكد من المحتوى. قاعدة البيانات تحفظ الردود الخاصة في جدول لا يقرأه إلا حساب مصرح به.

للوصول إلى الإدارة، أضيفي بريد المنظم إلى `public.admin_allowlist` في SQL Editor، ثم أنشئي مستخدمًا في Authentication > Users بنفس البريد واضبطي له كلمة مرور. سجّلي الدخول من رابط `/resala-third-gathering/?admin=1` بالبريد وكلمة المرور. إذا لم تريدي تأكيد البريد، أوقفي خيار `Confirm email` من Authentication > Sign In / Providers. أبقي قائمة البريد خالية من أي عنوان لا يحتاج إدارة الموقع؛ تبقى صلاحية الإدارة محكومة بقائمة السماح حتى بعد تسجيل الدخول.

اضبطي Auth URL Configuration بعد النشر:

- Site URL: `https://omarapdelgwad44.github.io/resala-third-gathering/`
- Additional Redirect URL: `https://omarapdelgwad44.github.io/resala-third-gathering/?admin=1`

خطة Supabase Free كانت مفعّلة عند إنشاء المشروع، لكن المشاريع قليلة النشاط قد تُوقَف مؤقتًا وفق سياسة Supabase. GitHub Pages يستضيف الملفات الثابتة مجانًا؛ وظائف RSVP والإدارة تعتمد على إتاحة Supabase.

## نشر GitHub Pages

سير العمل في `.github/workflows/pages.yml` يبني الموقع وينشره عند كل push إلى `main`. يحتاج مستودع GitHub إلى تفعيل Pages باستخدام GitHub Actions. متغيرا `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY` قيم واجهة عامة ويمكن تخزينهما كـ repository variables؛ لا تستخدم GitHub Secrets لمفتاح service-role لأنه غير مطلوب أصلًا.

قبل مشاركة الرابط العام، أدخلي التفاصيل المؤكدة واحفظيها كمسودة، راجعي المعاينة، ثم فعّلي مربع «نشر الدعوة للعامة». يمكن إبقاء RSVP مغلقًا بإخفاء القسم حتى اعتماد الاستقبال.
